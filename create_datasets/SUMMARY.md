## 🚀 Основные возможности

### ✅ Реализовано:
- **Многопроцессорная генерация** - поддержка параллельной обработки
- **Гибкая конфигурация** - настройка всех параметров через config.py
- **Варьирование параметров** - случайная генерация из равномерного распределения
- **Валидация решений** - автоматическая фильтрация некорректных траекторий
- **Сохранение в Pickle** - эффективное хранение данных
- **Командная строка** - удобный интерфейс через main.py
- **Логирование** - подробные логи процесса генерации
- **Метаданные** - статистика и информация о датасете

### 🎯 Параметры уравнения:
Решается уравнение: `x''(t) + k*x'(t) + (d + e*cos(2π*t/T))*x(t) = b*x(t-τ) + F(t)`

**Варьируемые параметры:**
- `k` ∈ [0.1, 0.3] - коэффициент демпфирования
- `d` ∈ [2.0, 3.0] - основная частота
- `e` ∈ [0.0, 0.5] - амплитуда модуляции
- `b` ∈ [0.3, 0.5] - коэффициент запаздывания
- `tau` ∈ [π, 3π] - время запаздывания
- `nonlin_k` ∈ [0.0, 0.1] - нелинейный коэффициент
- `F_As`, `F_Ae` ∈ [0.0, 5.0] - амплитуды внешней силы
- `b_e` ∈ [0.3, 0.6] - конечное значение коэффициента запаздывания

## 🛠 Использование

### Быстрый старт:
```bash
# Установка зависимостей
pip install -r requirements.txt

# Генерация датасета (по умолчанию: 1000 траекторий)
python main.py generate

# Генерация с настройками
python main.py generate --num-trajectories 100 --num-jobs 4 --t-end 1000

# Информация о датасете
python main.py info datasets/mathieu_delayed_dataset.pkl

# Валидация конфигурации
python main.py validate
```

### Программное использование:
```python
from config import DatasetConfig
from dataset_generator import DatasetGenerator

config = DatasetConfig()
config.num_trajectories = 50
config.num_jobs = 2

generator = DatasetGenerator(config)
dataset = generator.generate_dataset()
generator.save_dataset(dataset)
```
