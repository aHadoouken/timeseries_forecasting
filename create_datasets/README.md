# Генератор датасета решений уравнения Матье с запаздыванием

Этот проект предназначен для создания датасетов, состоящих из множества решений модифицированного уравнения Матье с запаздыванием с различными параметрами.

## Описание уравнения

Решается модифицированное уравнение Матье с запаздыванием:

```
x''(t) + k*x'(t) + (d + e*cos(2π*t/T))*x(t) = b*x(t-τ) + F(t)
```

где:
- `k` - коэффициент демпфирования
- `d` - основная частота
- `e` - амплитуда модуляции
- `T` - период модуляции
- `b` - коэффициент запаздывания
- `τ` - время запаздывания
- `F(t)` - внешняя сила (опционально)

## Использование


## Конфигурация

Основные параметры конфигурации можно изменить в файле [`config.py`](config.py:1):

### Параметры датасета
- `num_trajectories`: Количество траекторий (по умолчанию: 1000)
- `num_jobs`: Количество процессов для параллельной обработки (по умолчанию: 4)
- `output_dir`: Директория для сохранения (по умолчанию: "datasets")
- `dataset_name`: Имя датасета (по умолчанию: "mathieu_delayed_dataset")

### Параметры интегрирования
- `t_end`: Время интегрирования (по умолчанию: 5000)
- `dt`: Шаг интегрирования (по умолчанию: 0.01)
- `transient_time`: Время переходного процесса (по умолчанию: 100)

### Варьируемые параметры

Следующие параметры варьируются из равномерного распределения:

| Параметр | Диапазон | Описание |
|----------|----------|----------|
| `k` | [0.1, 0.3] | Коэффициент демпфирования |
| `d` | [2.0, 3.0] | Основная частота |
| `e` | [0.0, 0.5] | Амплитуда модуляции |
| `b` | [0.3, 0.5] | Коэффициент запаздывания |
| `tau` | [π, 3π] | Время запаздывания |
| `nonlin_k` | [0.0, 0.1] | Нелинейный коэффициент демпфирования |
| `F_As` | [0.0, 5.0] | Начальная амплитуда внешней силы |
| `F_Ae` | [0.0, 5.0] | Конечная амплитуда внешней силы |
| `b_e` | [0.3, 0.6] | Конечное значение коэффициента запаздывания |

### Константные параметры

| Параметр | Значение | Описание |
|----------|----------|----------|
| `T` | 2π | Период модуляции |
| `F_ts` | 0 | Время начала изменения внешней силы |
| `F_te` | 10 | Время окончания изменения внешней силы |
| `F_T` | 2π/3 | Период внешней силы |
| `b_ts` | 2000 | Время начала изменения коэффициента запаздывания |
| `b_te` | 2300 | Время окончания изменения коэффициента запаздывания |

## Структура данных

Каждая траектория в датасете содержит:

```python
{
    'id': int,                    # Уникальный идентификатор
    'parameters': dict,           # Параметры уравнения
    'solution': {                 # Решение
        't': np.array,            # Временные точки
        'x': np.array,            # Значения x(t)
        'x_dot': np.array         # Значения x'(t)
    },
    'metadata': {                 # Метаданные решения
        'max_amplitude': float,   # Максимальная амплитуда
        'mean_amplitude': float,  # Средняя амплитуда
        'std_amplitude': float,   # Стандартное отклонение
        'duration': float,        # Длительность
        'num_points': int,        # Количество точек
        'sampling_rate': float,   # Частота дискретизации
        'mean_period': float,     # Средний период (если найден)
        'std_period': float,      # Стандартное отклонение периода
        'num_peaks': int          # Количество пиков
    }
}
```

## Многопроцессорная обработка

Проект поддерживает параллельную генерацию траекторий с использованием модуля `multiprocessing`. Количество процессов можно настроить через параметр `num_jobs`.

Рекомендации:
- Для CPU с 4 ядрами: `num_jobs = 4`
- Для CPU с 8 ядрами: `num_jobs = 6-8`
- Не рекомендуется устанавливать `num_jobs` больше количества физических ядер

## Фильтрация траекторий

Система автоматически фильтрует некорректные траектории:
- Проверка на NaN и Inf значения
- Контроль амплитуды (min: 0.01, max: 100.0)
- Проверка стабильности решения
- Исключение взрывающихся решений

## Примеры использования в коде

### Загрузка датасета

```python
import pickle
import numpy as np

# Загрузка датасета
with open('datasets/mathieu_delayed_dataset.pkl', 'rb') as f:
    dataset = pickle.load(f)

# Получение траекторий
trajectories = dataset['trajectories']
print(f"Загружено {len(trajectories)} траекторий")

# Пример работы с первой траекторией
first_trajectory = trajectories[0]
t = first_trajectory['solution']['t']
x = first_trajectory['solution']['x']
params = first_trajectory['parameters']

print(f"Параметры: k={params['k']:.3f}, d={params['d']:.3f}")
print(f"Длительность: {t[-1]:.1f}, точек: {len(t)}")
```

### Анализ параметров

```python
# Извлечение всех значений параметра k
k_values = [t['parameters']['k'] for t in trajectories]
print(f"k: среднее={np.mean(k_values):.3f}, std={np.std(k_values):.3f}")

# Извлечение метаданных
amplitudes = [t['metadata']['max_amplitude'] for t in trajectories]
print(f"Амплитуды: среднее={np.mean(amplitudes):.3f}")
```

## Устранение неполадок

### Ошибки компиляции jitcdde
Если возникают проблемы с компиляцией, попробуйте:
```bash
pip install --upgrade jitcdde symengine
```

### Проблемы с памятью
Для больших датасетов уменьшите `num_trajectories` или увеличьте виртуальную память.

### Медленная генерация
- Увеличьте `num_jobs` (но не больше количества ядер CPU)
- Уменьшите `t_end` или увеличьте `dt`
- Уменьшите `transient_time`
